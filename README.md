<p style="text-align: justify;">
AIGI-VC database is a quality assessment database for AI-generated images in visual communication, which studies the communicability of AIGIs in the advertising field from the perspectives of information clarity and emotional interaction. The dataset consists of 2,500 images spanning 14 advertisement topics and 8 emotion types. It provides coarse-grained human preference annotations and fine-grained preference descriptions, benchmarking the abilities of IQA methods in preference prediction, interpretation, and reasoning.

## 📁 Dataset Details

This section describes the contents and structure of the AIGI-VC dataset, including the image files and annotation JSON files.

### 1. Image Archive: `AIGI-VC.zip`

- Contains **2,500 AI-generated images**
- Images are generated by **5 different generative models**

### 2. Coarse-grained Preference Annotations: `winrates.json`
This file contains **pairwise coarse-grained human preference choices**.

Each entry records the **preference probability (win rate)** that the first image in a pair is preferred over the second image under two evaluation dimensions.

**Example entry**:

```json
{
  "prompt": "...",
  "emotion": "Sadness",
  "name1": "22-0-sd2.png",
  "name2": "22-1-dalle3.png",
  "communicability_win_rate": 0.13025874359874545,
  "emotion_win_rate": 0.2615012842230031
}
```
**Field Description**:
- **`prompt`**  
  Text prompt used to generate the image pair.

- **`emotion`**  
  Intended emotion category associated with the image pair.

- **`name1`**, **`name2`**  
  File names of the two images forming a comparison pair.

- **`communicability_win_rate`**  
  Ground-truth coarse-grained preference probability (expressed as win rate) that **`name1`** is preferred over **`name2`** in the **information clarity** dimension.

- **`emotion_win_rate`**  
  Ground-truth coarse-grained preference probability (expressed as win rate) that **`name1`** is preferred over **`name2`** in the **emotional interaction** dimension.
  
### 3. Challenge-specific Preference Files

The following files contain subsets of coarse-grained preference annotations corresponding to the three challenges defined in the main paper:
    
- **`winrates-I.json`**
- **`winrates-II.json`**
- **`winrates-III-N.json`**  
- **`winrates-III-P.json`**

These files are derived from `winrates.json` and are used for **challenge-specific experimental settings**.

### 4. Fine-grained Preference Descriptions

The dataset provides human-written fine-grained preference descriptions for interpretation
and reasoning evaluation.

- **`gold_description_ic.json`**
  Fine-grained preference descriptions for the information clarity dimension.
- **`gold_description_ei.json`**
  Fine-grained preference descriptions for the emotional interaction dimension.

**Example entry (gold_description_ic.json)**:

```json
{
  "communicability_win_rate": 0.13025874359874545,
  "id": 1,
  "name1": "22-0-sd2.png",
  "name2": "22-1-dalle3.png",
  "prompt": "A close-up image of a broken picture frame with a happy family photo inside, placed on a dark wooden surface.",
  "reason": "1. The first image has lower sharpness compared to the second image, resulting in less defined details. ..."
}
```

**Field Description**:
- **`communicability_win_rate`**  
Ground-truth coarse-grained preference probability in the **information clarity** dimension.

- **`id`**  
Entry index.

- **`name1`**, **`name2`**   
  Image pair being compared.

- **`prompt`**  
  Text prompt used to generate the images.

- **`reason`**  
  Reference **fine-grained human preference description**, used for **interpretation and reasoning performance evaluation**.
